# Portfolio setup

1. Create a public repo named `bsportsman1.github.io` (or any repo name) and upload `index.html`.
2. Repo Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
3. Your URL will be `https://bsportsman1.github.io/` (or `/repo-name/`).
4. In Google Drive, make a folder for CAD, code, and photos. Share it as "Anyone with the link can view". Paste that link over `DRIVE_LINK_HERE` in `index.html`.
5. Make the QR code from your final GitHub Pages URL (any free generator, e.g. qr-code-generator.com or Adobe Express). Download as PNG or SVG and place it on the resume. Test it with a phone before sending.

## Adding a project
Copy one object in the `projects` array, edit it, commit. Empty fields (`TODO`) show a "not written yet" note.
